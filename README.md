# segnoQR
Very simple python script for QR code generation. Includes gui
## What this tool does?
So, let's think that you in situation where you need to transfer some text or website to your phone. But, for some reason you can't do it via telegram, bluetooth or smth. Here you may need my program! Simple text transmission as is! You can just drop exe (if you don't like cli tools) and just run it. You don't even need python! So it makes possible to transfer information everywhere, even on public computers
## Usage
- run standalone .exe (segnoQR.exe stangs for Russian language and segnoQR_en.exe stands for english language)

  Or you can run this tool in command line (python3 required) Change segnoQR.pyw to segnoQR_en.pyw if you need english
  ```
  pip install -r requirements.txt
  python segnoQR.pyw
  ```
